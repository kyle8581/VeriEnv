# BrowserGym PAE

PAE (Practical Agent Environment) benchmark for BrowserGym.

Tasks involve navigating real-world websites to complete specific goals.

## Tasks

- BestBuy--19: Find the most affordable 3D printer suitable for hobbyists
- Simply Recipes--6: Discover a recipe for a classic Italian pasta dish
- Walmart--20: Find the best-selling air fryer and read product reviews
- Yummly--7: Find recipes for making homemade bread or baked goods
- Food.com--23: Locate a recipe for a classic French or Italian appetizer
- Simply Recipes--2: Locate a vegetarian main dish recipe for a dinner party
- Apple--18: Check trade-in offers for the latest iPhone model
